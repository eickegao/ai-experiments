# 草原沙盘

[English](README.md) · 中文说明

一个摆在桌面上的非洲草原上帝游戏，由 AI 一口气写出来。兽群吃草喝水，狮群捕猎，两个部落采集、打猎、种田、盖房，从一堆篝火发展成带城墙的石头王城，还会隔着河开战。你是神：降雨、闪电、野火、陨石、干旱、暴雨、隆起和压低地面。

为频道 [**Build with AI**](https://www.youtube.com/@buildwithai2027) 和 [**独立营业中**](https://www.youtube.com/@独立营业中) 制作，更多内容见 [videodoz.com](https://videodoz.com)。

状态：演示版（2026-11-20），还没有审核发布。

## 做什么、为什么

视频要回答的问题：现在的 AI 模型从零做一个完整的游戏，能做多好、多快？这个目录就是答案本身（游戏），加上制作过程的记录。

## 怎么做出来的

- 模型：Claude Fable 5.2（`claude-fable-5-2`），在 Claude Code 里和频道主的一次对话中完成。
- 人负责定题（非洲草原上的上帝沙盒，有动物、打猎、自然灾害和两个打仗的部落）和审核结果。全部代码和场景里的全部模型由 AI 编写。
- 模型有两代。第一个可玩版本完全没有美术素材：每只动物、每个人、每棵树、每座房子都是用代码拿方块、圆柱、圆锥搭出来的（`js/models.js`，现在作为后备，`?assets=0` 可以切回去）。频道主觉得这种长相太简陋，于是 AI 又调用另外两个 AI 生成了 25 个模型：每个物体先用 OpenAI 图像接口（`gpt-image-2`）出一张参考图，再用 Tripo（`v2.5-20250123`，每个 30 点、约一分钟）转成带贴图的 3D 模型。`tools/make_assets.py` 负责这两步，并把提示词、任务号、用时和点数记在 `assets/manifest.json`；GLB 文件在 `assets/models/`。没有任何东西是人手画或手工建模的。
- 依赖：three.js r187 和它的 GLTF 加载器，放在 `vendor/three/`。
- AI 自己检查成果：用无头 Chrome 打开页面、截图、看图（`tools/shot.py`、`tools/scenario.py`、`tools/probe.py`）。
- 第一个可玩版本：从空目录开始，实际用时约 36 分钟，约 3100 行 JavaScript。

## 设计

- **世界**（`js/terrain.js`、`js/flora.js`）：96 × 96 的高度图地块，有一条河、一个湖、一个水塘和三处岩石堆，放在木托盘上。草、烧痕、水位是同一张网格上的数据；金合欢树、猴面包树、浆果丛、石头和草丛是实例化网格。
- **野生动物**（`js/animals.js`）：斑马、角马、瞪羚成群吃草、去水边、繁殖、逃跑；大象和长颈鹿游荡；狮群在岩石堆休息，饿了就捕猎；秃鹫在尸体上空盘旋。
- **部落**（`js/tribes.js`）：人会采浆果、三人一组打猎、种田、盖房、生孩子。村子经历四个时代（营地、村落、城寨、王城），每个时代有自己的建筑。战鼓一响，战士集结、行军、交战。
- **神力**（`js/env.js`）：降雨、闪电、陨石、隆起、下陷、召唤兽群、干旱、暴雨、战鼓。火顺着风在干草里蔓延，烧掉树和茅草屋，雨能把它浇灭。
- **画面**（`js/stage.js`、`js/post.js`）：昼夜变化、柔和阴影，以及一遍后处理：景深（微缩模型感）、电影感色调映射、暗角。
- **可复现**：模拟按固定的 1/30 秒步长运行，随机数由种子生成，同样的种子和同样的操作会得到同样的过程。

## 怎么运行

ES 模块必须通过 http 加载，所以要起一个本地服务：

```bash
cd savanna-sandbox
python3 -m http.server 8000
# 打开 http://localhost:8000/
```

网址参数：`lang=zh|en`、`seed=<数字>`、`demo=1`（50 秒的自动演示）、`ui=0`（隐藏界面）、`post=0`（关闭后处理）、`debug=models`（全部模型的展示）。

工具（需要 `pip install -r requirements.txt` 和本机的 Chrome）：

```bash
python3 tools/shot.py 5 20 --eval "G.setSpeed(16)"      # 在第 5 秒和第 20 秒截图
python3 tools/scenario.py war                             # 带截图的脚本化测试
python3 tools/capture.py out/demo.mp4 50 [--portrait]     # 逐帧精确录制自动演示
```

## 输出文件

- `out/`（不入库）：截图和录屏。
- `capture.py` 还会写出 `<名字>.events.json`，是模拟的事件记录（时代更替、捕杀、火灾、战争）和时间戳，做视频时用来对音效。
